# AnalysisLabel

The hero's featured product, typeset like a regulatory label on a sack. Provide (filter `kudino_featured_label`): name, short description, N-P-K, SKU, dose rows, price and an add-to-cart link.

- A 1.5px `kd-ink` frame on `kd-sheet`. No radius, no shadow.
- The table: Persian name, chemical formula in mono (P<sub>2</sub>O<sub>5</sub>), percentage.
- Use it only once per page.
