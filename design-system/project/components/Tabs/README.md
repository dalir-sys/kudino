# Tabs

Underline tabs to filter one list. Provide: buttons with `role="tab"` and `aria-selected`, a `data-group` per tab, and `data-kd-filter="#grid"` on the container.

- The count sits in a small mono `sup` next to each label so the result is predictable.
- The active underline is 2px `kd-field` and slides in from the start side.
- Don't: use pills or segmented controls; the system has none.
