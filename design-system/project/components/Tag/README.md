# Tag

One or two words on a product image or next to a name. Nearly square (`kd-r-1`), 22px tall.

- `--ink`: discount percentage only. Default: a neutral label (ارگانیک، تازه). `--field`: the week's pick. `--warn`: a warning.
- `kd-stock`: availability. In-stock is shown only on the product page; on the shelf, only «فقط ۳ عدد مانده» or «ناموجود» appears, because that is the exception.
