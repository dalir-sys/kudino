# PrescriptionSlip

The consult request, set as a slip with a perforated edge and ruled fields. Provide: mobile number, crop and area; the form posts to your own handler (the theme confirms in place by default with `data-kd-fake-submit`).

- The header carries the request number in mono (`RX / 1405-08`).
- The last line states exactly what the number is used for.
