# ElementTable

Shop by deficiency sign, like a periodic table. Each cell: atomic number, macro/micro class, symbol in mono 44px, Persian name and the visible sign on the leaf.

- Only N, P and K carry a 3px band in their data colour along the top edge.
- On hover the cell turns `kd-ink`. On mobile it is two columns.
- Each sign must be real agronomic copy; no filler.
