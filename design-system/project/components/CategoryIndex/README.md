# CategoryIndex

Fertilizer families as an editorial index (a catalogue table of contents), not tiles. Provide: name, one-line description, count and link.

- A two-digit mono number, the name in Markazi at 28px, the description in `kd-ink-3`, the count at the end.
- On hover the row gets a `kd-paper-2` ground and moves 12px inward. On mobile it is a single column.
