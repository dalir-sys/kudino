# Illustrations

Flat, print-style pack drawings shown in place of a product photo: kraft pouch (`pack-pouch`), woven sack (`pack-sack`) and HDPE jug (`pack-jug`). A 1.5px `kd-ink` line, one print colour per category, the analysis in mono.

- In the theme they are generated by `kudino_pack_svg( $type, $color, $code, $name )`; these files are samples of the same output.
- The text inside them uses page fonts; when opened standalone (`<img>`) the font falls back to the system font.
- Always on a `kd-paper-2` ground. A real product photo always wins over the drawing.
