# Logos

`kudino-mark.svg`: three bars in `kd-n`, `kd-p` and `kd-k`, an N·P·K analysis drawn as a bar chart. The bar heights stay fixed (24, 15, 20 on a 26 grid).

- The mark always sits to the start side of the wordmark «کودینو», set in Markazi Text 700. The wordmark is live text, not an image.
- On `kd-ink` the bars keep their colours and only the wordmark turns `kd-paper`.
- Minimum size 20px. Don't rotate, outline or recolour the mark.
